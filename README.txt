FUELTRACK — PHONE APP

What is included:
- Dark purple mobile-friendly food diary.
- Daily calorie, protein, carbohydrate and fat totals.
- Breakfast, lunch, dinner and snack categories.
- Meal photo selection/camera capture with preview.
- Entries saved locally in the browser on this device.
- Installable PWA support and offline app shell.

IMPORTANT:
The photo picker is included, but automatic AI food recognition is NOT connected.
The app does not guess nutrition from a photo. Enter nutrition from a label,
measured portion or trusted source.

HOW TO PUBLISH AND INSTALL:
1. Upload all files in this folder to a static HTTPS host (for example GitHub Pages).
2. Open the published HTTPS address in Chrome on your Android phone.
3. Open Chrome's menu (three dots) and choose "Install app" or "Add to Home screen".
4. Launch FuelTrack from the new home-screen icon. It opens in its own app-style window.

The PWA service worker requires HTTPS (or localhost). Opening index.html directly
from the file manager will let you test the page, but installation/offline support
will not work properly.

Privacy:
Diary entries are stored in this browser's local storage. Clearing browser site
data can erase them. No server or account sync is included.
